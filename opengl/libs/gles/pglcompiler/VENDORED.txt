Vendored mesa compiler source tree (shared front half)
======================================================

PURPOSE
  On-device GLSL -> linked NIR frontend shared by every GPU-backed EwokOS
  machine (pglcompiler.h contract).  The machine backends (V3D NIR->QPU on
  raspi5/raspix, Adreno NIR->ir3 on q8b) consume the NIR this tree produces
  to compile shadertoy fragment shaders and the geometry compute kernels at
  runtime.  See the plan "PGL_G3D Adreno backend port".

UPSTREAM PIN  (version-consistency anchor)
  repo    : https://gitlab.freedesktop.org/mesa/mesa.git  (branch main)
  commit  : f45825a0c724d06f231a1210484fe9af71a3ffab
  date    : 2026-09-04 01:24:43 +0000
  subject : Revert "intel/brw: keep texture ops in large loops"

  WHY THIS COMMIT: the V3D back half now vendored under
  machines/raspi5|raspix/system/libs/v3dcompiler/mesa/src/broadcom/compiler
  originated as a clean mesa-main snapshot. At this commit ALL 28 of its
  .c/.h files (nir_to_vir.c, vir_to_qpu.c, vir_register_allocate.c,
  qpu_schedule.c, v3d_compiler.h, every v3d_nir_lower_*.c, ...) are
  BYTE-IDENTICAL to that snapshot, and nir_opt_gcm has the 3-arg signature
  (nir_opt_gcm(shader, value_number, keep_texture_ops_in_large_loops)) that
  nir_to_vir.c calls. The very next commit (859fcc3b) reverts that
  nir_opt_gcm option back to 2 args, so this is the exact last-consistent
  pin.  Every machine back half must stay at the same pin as this tree.

VENDORED SUBTREES  (under mesa/src/, preserving mesa's include layout)
  compiler/nir/        NIR (all passes) + generated opcode/intrinsic sources
  compiler/glsl/       GLSL -> NIR frontend, incl. glcpp/ preprocessor
  compiler/*.c/*.h     glsl_types, shader_enums, shader_info, list, builtin_types
  util/                ralloc, hash_table, dynarray, math, format/, ...
  c11/                 threads/compat headers

  GPU BACKENDS ARE NOT HERE.  This tree is the shared, device-neutral front
  half only (pglcompiler = GLSL -> linked NIR).  Each machine vendors its own
  mesa back half next to the glue that implements pglcompiler.h, at the same
  upstream pin:
    machines/raspi5/system/libs/v3dcompiler/mesa/src/broadcom/   V3D (NIR->QPU)
    machines/raspix/system/libs/v3dcompiler/mesa/src/broadcom/   V3D (NIR->QPU)
    machines/q8b/system/libs/adrenocompiler/mesa/src/freedreno/  Adreno (NIR->ir3)
  Those backends include this tree's headers through PGLC_FE_DIR.

  Include roots needed by the build:  -I mesa/src (compiler/nir/nir.h,
  util/ralloc.h, util/format/u_format.h resolve via -I src).

HOST-GENERATED FILES  (device build has NO python/bison/flex/mako)
  mesa reproduces these at build time; here they are pre-generated on the host
  and committed. Regenerate with ./regen_codegen.sh (see that script for the
  exact commands). Tools used: GNU bison 3.8.2, flex 2.6.4, python 3.9 +
  mako 1.3.12 + PyYAML 6.0.3.
    compiler/builtin_types.{h,c}              compiler/ir_expression_operation.h
    compiler/nir/nir_opcodes.{h,c}            compiler/nir/nir_builder_opcodes.h
    compiler/nir/nir_constant_expressions.c   compiler/nir/nir_intrinsics*.h/.c
    compiler/glsl/glsl_parser.{cpp,h}  (bison) compiler/glsl/glsl_lexer.cpp (flex)
    compiler/glsl/ir_expression_operation_{constant,strings}.h
    compiler/glsl/{float64,bc1,bc4,etc2_rgba_stitch,astc}_glsl.h,
                  cross_platform_settings_piece_all.h   (xxd-embedded .glsl)
    compiler/glsl/glcpp/glcpp-parse.{c,h} (bison) glcpp-lex.c (flex)
    util/format/u_format_{gen.h,pack.h,table.c}  util/format_srgb.c
  Backend-generated files (V3D v3d_nir_lower_algebraic.c and the cle pack
  headers, Adreno isa/encode.h and ir3_nir_*.c) are NOT here; they live and
  are regenerated with their backends under machines/<hw>/system/libs/.

DELIBERATE DEVIATIONS FROM UPSTREAM
  * nir_opt_algebraic.c NOT vendored: the generated file is ~49 MB / 3.76 M
    lines, impractical to commit and to compile on-device. WS2 supplies a stub
    defining the six entry points (nir_opt_algebraic, _before_ffma,
    _before_lower_int64, _late, _distribute_src_mods, _integer_promotion) as
    no-op "return false". Correctness is preserved; only the generic algebraic
    optimisation is skipped (each backend's own smaller lowering - V3D's
    v3d_nir_lower_algebraic, ir3's ir3_nir_* passes - still runs). Regenerate
    the full file with regen_codegen.sh if a beefier build host is available.
  * NOT vendored: compiler/spirv/ (the GLSL frontend does not reference it;
    SPIR-V is out of scope), gtest/ and every tests/ subdir (unit tests only).
  * NOT generated (stub in WS2 only if a vendored file references them):
    util/driconf_static.h, util/shader_stats.h, git_sha1.h (build stamp).
    Backend-side debug headers (e.g. V3D's cle/v3d_xml.h for the v3d_decoder
    path) are the machine backends' concern.
